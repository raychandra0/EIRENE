eirenex
version: 1.0.4
Author: Nathan Bartlett

        This is the main README for the EireneX post-processing script. EireneX is a Python module developed to organize
                input and output data for EIRENE standalone runs using the xarray Python library. It is under
                development by Nathan Bartlett who can be contacted at bartlettnbb2@gmail.com.

        The repository consists of the following:

                        README.txt             : High level overview of the repository contents
                        eirenex_manual.pdf     : Manual for the package with a step by step guide for use
                        license                : ???
                        requirements.txt       : A list of modules that are needed to run the program
                        docs                   : Detailed documentation managed with the Sphinx Python package
                        eirenex                : The actuals scripts that compose the code
                        samples                : Example runs using EireneX
